## Проект. Модуль Collections
### Описание проекта
***Название проекта: «Контактная книга»***  
***Суть проекта:***  
Вы создадите консольное приложение, которое управляет списком контактов. Ваша задача — применить
все ключевые темы, пройденные в этом модуле: использование коллекций ( List , Set , Map ), правильное
переопределение методов equals и hashCode , а также обход коллекций через итераторы.

***Ваше приложение «Контактная книга» должно уметь:***  
* **Добавлять** новые контакты.  
* **Удалять** существующие контакты.  
* **Просматривать** все контакты в порядке добавления.   
* **Искать** контакт по имени или по группе.
* **Группировать** контакты по категориям (например, «Работа», «Семья», «Друзья» и т.д.).
* **Гарантировать** уникальность контактов за счёт корректной реализации equals и hashCode .
### Детальное описание задания
#### Класс Contact
Создайте класс Contact со следующими полями:  
* String name — имя и фамилия контакта.
* String phone — номер телефона.
* String email — адрес электронной почты.
* String group — категория (например, «Работа», «Семья», «Друзья»).  

**Что важно сделать:**
1. Переопределить equals и hashCode :
   * Решите, на основе каких полей контакты считаются уникальными (например, name и phone ).
   * Убедитесь, что при добавлении двух контактов с одинаковыми значениями «ключевых» полей,
      второй контакт не попадёт в коллекцию или перезапишет прежний.
2. Настроить toString() :
   * Напишите удобный вывод информации о контакте, чтобы при печати контактов в консоль
     пользователь видел основные поля.
### Структуры данных
   Выберите подходящие коллекции для различных задач:
1. **List** (например, ArrayList ):  
   Хранит контакты в порядке добавления, чтобы вы могли показывать их в «исходном» порядке.
2. **Set** (например, HashSet ):  
   Проверка уникальности контактов. Если контакт уже есть в наборе — значит, дубликат.
3. **Map** (например, HashMap ):
* Группировка контактов по категориям. Ключ — это название группы, значение — список контактов в
    этой группе.
### Основные операции
Ваше приложение должно уметь следующее:
1. **Добавление контакта**  
* Считывать данные (имя, телефон, email, группа) от пользователя.
* Создавать объект класса Contact .
* Проверять, нет ли уже такого контакта (используя Set ).
   Если контакт уникален, добавлять его в List , Set и соответствующую запись Map .
2. **Удаление контакта**  
* Удалять существующий контакт по имени или другому уникальному идентификатору (на ваше
   усмотрение).
* При удалении контакт должен пропадать из всех структур (списка, набора, карты).
3.**Просмотр всех контактов**  
* Выводить список контактов в том порядке, в каком они были добавлены.
* Для обхода List используйте итератор.
4. **Поиск контакта**  
* Искать и выводить контакт(ы) по имени.
* Или, например, искать по номеру телефона.
* В любом случае, вы можете использовать коллекции для быстрого поиска.
5. **Просмотр контактов по группе**  
* Спрашивать пользователя: «Введите название группы».
* Искать соответствующий список в Map и выводить контакты этой группы (опять же с итератором).
   ### Консольное меню
   Реализуйте простой цикл ввода команд:
   * «1»: Добавить контакт
   * «2»: Удалить контакт
   * «3»: Посмотреть все контакты
   * «4»: Найти контакт
   * «5»: Посмотреть контакты по группе
   * «0»: Выход
   Для каждой команды вызывайте соответствующий метод и/или логику. Организуйте проверку ошибок
   ввода (например, если пользователь вводит несуществующий пункт меню).
   ### Рекомендации по реализации
1. **Использование итераторов**   
   При выводе или обходе элементов коллекций ( List , Set ) стремитесь использовать итераторы, чтобы
   применить теорию на практике.
2. **Работа с Map**
   * Когда пользователь добавляет контакт, определите его группу.
   * Найдите или создайте в Map список для этой группы и добавьте туда контакт.
3. **Обработка ошибок**  
   * Если пользователь пытается добавить дубликат, уведомляйте об этом.
   * Если пользователь пытается удалить контакт, которого нет, выведите соответствующее сообщение.
4. **Дополнительная идея (не обязательно)**  
   * Можно сделать небольшие тестовые сценарии, записанные в коде, чтобы автоматически проверить
   корректность работы основных методов.
   ### Проверка и тестовые примеры
   После реализации проверьте ваше приложение с разными ситуациями:
   * Добавьте несколько контактов с разными группами («Работа», «Семья»).
   * Попробуйте добавить дубликат (такой же name и phone ). Приложение должно сообщить, что контакт
     уже существует.
   * Удалите контакт, а затем убедитесь, что он исчез из списка, набора и мапы.
   * Просмотрите контакты в общем списке, а также по группам.
